### STEPS TO PRACTICE

1. Install uv

```
pip install uv
```

2. Create a venv

```
uv venv basicragenv
```

3. Activate a venv

```
basicragenv\Scripts\activate
```


### STEPS FOR GIT AND GITHUB

1. Install git
2. Make an id on Github
3. Make a repo on Github
4. make a .gitignore file
5. Write commands in terminal in VS Code

```
git add .
```

```
git commit -m "some message"
```

```
git push
```
